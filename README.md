# worshipsync-wake

Будильник для тестового сервера WorshipSync v2 на Render: кожні ~10 хвилин відкриває `/api/health`,
щоб безкоштовний сервер не засинав і нагадування в боті приходили вчасно.

Якщо в репозиторії 60 днів нічого не змінювалось, GitHub призупиняє розклад — тоді Actions → wake → «Enable workflow».
